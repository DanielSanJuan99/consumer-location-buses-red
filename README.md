# Consumer Location - Buses RED 📍💾

Microservicio consumidor que lee ubicaciones GPS de buses desde RabbitMQ y las persiste en Oracle Autonomous Database.

## Tecnologías

- Java 21 (Eclipse Temurin)
- Spring Boot 3.5.7
- Spring Data JPA / Hibernate 6.6.33
- Oracle Autonomous Database (Wallet mTLS)
- Spring AMQP (RabbitMQ)
- Maven 3.9.9
- Docker (multi-stage build)

## Tabla Oracle: BUS_LOCATIONS

| Columna | Tipo | Descripción |
|---|---|---|
| `ID_UBICACION` | NUMBER (PK, Sequence) | ID autoincremental |
| `ID_BUS` | VARCHAR2(50) NOT NULL | Identificador del bus |
| `LATITUD` | FLOAT NOT NULL | Latitud GPS |
| `LONGITUD` | FLOAT NOT NULL | Longitud GPS |
| `FECHA_RECIBIDO` | TIMESTAMP NOT NULL | Timestamp del mensaje |
| `RUTA` | VARCHAR2(50) | Ruta del bus |
| `VELOCIDAD` | FLOAT | Velocidad en km/h |
| `CREADO_EN` | TIMESTAMP NOT NULL | Fecha de inserción (auto) |

> Hibernate está en modo `ddl-auto: none`. La tabla debe existir previamente en Oracle.

### SQL de creación

```sql
CREATE TABLE BUS_LOCATIONS (
    ID_UBICACION NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    ID_BUS VARCHAR2(50) NOT NULL,
    LATITUD FLOAT NOT NULL,
    LONGITUD FLOAT NOT NULL,
    FECHA_RECIBIDO TIMESTAMP NOT NULL,
    RUTA VARCHAR2(50),
    VELOCIDAD FLOAT,
    CREADO_EN TIMESTAMP NOT NULL
);

CREATE SEQUENCE bus_location_seq START WITH 1 INCREMENT BY 1;
```

## Variables de Entorno

| Variable | Descripción | Default |
|---|---|---|
| `RABBITMQ_HOST` | Host de RabbitMQ | `rabbitmq` |
| `RABBITMQ_PORT` | Puerto de RabbitMQ | `5672` |
| `RABBITMQ_USERNAME` | Usuario RabbitMQ | *(requerido)* |
| `RABBITMQ_PASSWORD` | Contraseña RabbitMQ | *(requerido)* |
| `ORACLE_USERNAME` | Usuario Oracle | `ADMIN` |
| `ORACLE_PASSWORD` | Contraseña Oracle | *(requerido)* |
| `WALLET_PATH` | Ruta del Wallet dentro del contenedor | `/app/wallet` |

## Configuración de Variables de Entorno

El proyecto incluye un archivo `.env.example` con las variables necesarias:

```bash
# Copiar el archivo de ejemplo
cp .env.example .env

# Editar con tus valores (ORACLE_PASSWORD es obligatorio)
nano .env
```

**Variables críticas sin valor por defecto:**

| Variable | Requerida | Default en docker-compose | Descripción |
|---|---|---|---|
| `ORACLE_PASSWORD` | ⚠️ **Sí** | *(ninguno)* | Contraseña de Oracle Autonomous DB |
| `RABBITMQ_USERNAME` | Sí | `admin` | Usuario RabbitMQ |
| `RABBITMQ_PASSWORD` | Sí | `admin123` | Contraseña RabbitMQ |

> **Importante:** `ORACLE_PASSWORD` **no tiene valor por defecto** en `docker-compose.yml`. Debe configurarse en un archivo `.env` en el mismo directorio del `docker-compose.yml` o exportarse como variable de entorno.

## Oracle Wallet

El Wallet se monta como volumen en el contenedor:

```yaml
volumes:
  - ./Wallet:/app/wallet:ro
```

**Archivos requeridos** en la carpeta `Wallet/`:
- `cwallet.sso`
- `tnsnames.ora`
- `sqlnet.ora` (con `DIRECTORY="/app/wallet"`)
- `ojdbc.properties` (con rutas apuntando a `/app/wallet`)
- `keystore.jks`, `truststore.jks`

> **Importante:** Los archivos `sqlnet.ora` y `ojdbc.properties` deben tener las rutas apuntando a `/app/wallet` (no a `${TNS_ADMIN}`). Además, la carpeta debe tener permisos `chmod 777` en la instancia EC2.
